# French Cards PWA, portfolio re-skin (Riso Blue house style)

Sample French-English vocabulary (about 120 everyday words in 6 themes, with review history); the interface is shown in English. Same screens and data as the parent folder, restyled at capture time only. Light only.

- 01-review-front.webp: Review card, question side (FSRS queue, 10 of 31 today)
- 02-review-answer.webp: Same card revealed with translation, example and the three grading buttons with intervals
- 03-add-suggestions.webp: Quick add: dictionary match plus suggestions with register levels (AI mocked)
- 04-import-result.webp: Word extraction from a French chat screenshot, with a low-confidence row to check (AI mocked)
- 05-themes.webp: Themes list with word counts and due markers
- 06-theme-words.webp: One theme's word list with levels, origins and review status
- 07-word-detail.webp: Word detail: origin, conjugation preview, second example
- 08-word-conjugation.webp: Word detail with the full present-tense conjugation table
- 09-exercises.webp: Exercise sets written in the chat, with progress per set
- 10-exercise-question.webp: Exercise in progress: conjugation question
- 11-exercise-answered.webp: Exercise answered correctly, with the stamped feedback
- 12-progress.webp: Progress: words known, daily trends, study calendar
- 13-settings.webp: Settings
- 14-search.webp: Library search across French and English
- 15-desktop-review.webp: Desktop layout: review with the card revealed, sidebar with themes (1440x900 @2)
- 16-desktop-library.webp: Desktop library table with the word detail pane (1440x900 @2)
- 17-desktop-progress.webp: Desktop progress page with trends and day detail (1440x900 @2)
