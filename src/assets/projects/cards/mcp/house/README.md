# French Cards MCP app, portfolio re-skin (Riso Blue house style)

Same widgets and data as the parent folder, restyled at capture time only. Light only.

- 01-cards-front.webp: Card player in the chat: question side
- 02-cards-flipped.webp: Card player flipped: translation, example and grading buttons
- 03-cards-done.webp: End-of-round summary with hard words and next steps
- 04-review-setup.webp: Review setup card: mode, themes and round size
- 05-exercise-setup.webp: Exercise setup card: themes, verb drill, size and level
- 06-exercise-question.webp: Exercise player: multiple-choice question in progress
- 07-exercise-answered.webp: Exercise answered with feedback and a short explanation
- 08-exercise-cloze.webp: Cloze question: fill the gap in a sentence
- 09-exercise-conjugation.webp: Conjugation question from a verb set
- 10-exercise-done.webp: Exercise summary: first-try score, mistakes, save and repeat
