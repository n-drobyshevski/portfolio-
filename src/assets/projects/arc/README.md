# Arc screenshots

Captured from the live web demo (https://arc-ko.vercel.app/?demo, a simulated EP-133). Desktop 1440x900 and phone 390x844, both at 2x.

- `00-cover-device.webp`: Cover: the EP-133 drawing, the phone device browser and a saved backup
- `01-live.webp`: Live: the EP-133 mirrored on screen as you play, with tools and the Claude beat prompt
- `02-live-one-group.webp`: Live in One group view: a large pad grid for a single group
- `03-backups.webp`: Backups library: every backup saved with its sound and project counts
- `04-backup-sheet.webp`: A backup sheet: details, notes, restore, share and compare
- `05-backup-contents.webp`: Backup contents: sounds you can play and the projects that use them, no device needed
- `06-device.webp`: Device browser: storage meter, sounds grouped by slot range, one-tap playback
- `07-device-project.webp`: A project selected on the device
- `08-project-pads.webp`: Project pads: which sound sits on each pad, group by group
- `09-guide.webp`: Shortcut guide: 100 EP-133 key combos drawn as the device keys, with search
- `10-settings.webp`: Settings: theme, device skin, auto-connect, library and Live options
- `11-whats-what.webp`: What is what: the guide overlay that labels every control
- `12-live-dark.webp`: Live in the dark theme
- `13-live-ep40-skin.webp`: Live with the EP-40 Riddim skin
- `14-mobile-live.webp`: Phone: Live pads
- `15-mobile-device.webp`: Phone: device browser
